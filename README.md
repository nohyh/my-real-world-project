# My RealWorld Project · 我的第一个全栈项目

这是我学习全栈开发时完成的第一个相对完整的前后端项目，对我来说更多是一份**成长记录**，所以保留这个仓库作为阶段性纪念。

项目参考 RealWorld / Conduit 类应用的前后端结构，包含独立的 frontend 与 backend，并围绕真实全栈项目常见的路由、接口、表单、数据库与前后端联调进行练习。

## 技术栈

### Frontend

- React
- Vite
- React Router
- TanStack Query
- Axios
- React Hook Form

### Backend

- Node.js
- Express
- Prisma
- 数据库持久化

## 项目结构

```text
my-real-world-project/
├── frontend/       # React + Vite 客户端
├── backend/        # Node / Express 后端
├── api.yml         # API 规范
└── Conduit.postman_collection.json
```

## 为什么保留这个仓库

它并不是我现在最成熟的项目，但它记录了我第一次真正把前端、后端、数据库和 API 联调串起来的过程。

后续的 NBA 数据平台、PPT Agent、Browser Agent 等项目，都是在这类基础全栈能力上继续往数据产品与 AI 应用方向扩展。

> 这个仓库主要作为学习轨迹保留，不代表我当前的工程能力上限。
